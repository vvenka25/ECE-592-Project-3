# Earlier three-counter treatment

This native/enclave collection and its original analysis are retained.
Native events support the intended STLB-miss/cache treatment, but this event
set does not include a simultaneous active-cycle clock comparison. Final
cost evidence uses `q8-clock-artemisia` with a fourth cycle counter. No raw
observation was discarded; the estimator was revised after Charnwood exposed
a shifted compact baseline. Enclave STLB-event coverage remains unqualified.
